CrafteosASD is an advanced crafting infrastructure plugin focused on creating progression-oriented, modular and highly customizable crafting systems.

Rather than simply adding recipes, the plugin was designed to completely control crafting progression and custom item integration.

Features:
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_crafting_table.png" width="16"> Custom crafting recipes
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_anvil.png" width="16"> Anvil recipes
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_blast_furnace.png" width="16"> Furnace systems
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_knowledge_book.png" width="16"> Recipe infrastructure
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_barrier.png" width="16"> Recipe blocking
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_hopper.png" width="16"> GUI editors
- <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_amethyst_shard.png" width="16"> Custom item integrations

Unlike traditional recipe plugins, CrafteosASD behaves as a complete crafting progression framework.

The command architecture inside CrafteosASD was designed around a GUI-oriented workflow.

Instead of manually editing complex configuration files, recipes and crafting systems can be managed directly in-game.

### <img src="https://raw.githubusercontent.com/ItsAsddd/ItsAsddd/main/mcicons/minecraft_redstone.png" width="18"> Centralized Management

Administrators can:
- create recipes
- modify crafting types
- block recipes
- edit outputs
- configure ingredients
- manage recipe stations
- reload systems dynamically

without requiring server restarts.

### <span style="color:#D6B37A"><b>Infrastructure-Oriented Design</b></span>

The plugin was specifically designed to support large crafting ecosystems rather than isolated recipes.

</details>
